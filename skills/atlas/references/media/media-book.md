# 图书介质

骨架与字段行格式见 `wiki-skeleton`；题记 / 文风 / 事实核查各自独立。**这里只写图书特有的部分。**

## 1. 本篇用的章名

- 第 3 章 = **故事背景与设定**
- 第 5 章 = **创作特色**（漫画常见小节：叙事结构 / 分镜与视觉 / 与改编作品的关系；小说：叙事结构 / 语言与文体 / 与改编作品的关系）
- 第 6 章 = **主要角色与创作团队**，末节固定核心关系简述；创作团队一节写作者、连载杂志或平台、出版方、译者
- **2.5 分卷 / 分册一览：需要读者逐卷查阅时才设**（形态见 §5）

## 2. 先判断体裁与组织形态（两件都判完才动笔）

**体裁**（漫画 / 轻小说 / 小说）先定，再定组织形态。同名作品常有漫画版与小说版并存（媒体库里尤其如此）：**按本条目要覆盖的那一版定体裁**，另一版只进 2.2 的版本与改编关系，不混写。

判据不足就查证，或写 `待核实`，**不要按印象猜**——把小说写成分镜分析、把漫画写成文体分析，都是体裁判错的直接症状。

| 形态 | 特征 | 做法 |
|---|---|---|
| 单作品多卷 | 一个连续故事分成多卷 | 一篇条目覆盖全作，卷信息进 2.5 |
| 一个作者或系列的多部独立作品 | 每部有自己的剧情和版本 | **各自成篇**，另设系列主文 |
| 合并合集 | 多个册次装订或打包在一起 | 主文承担合集信息，值得展开的分册再单独成篇 |
| 混合系列 | 正传、外传、前传或多作者并存 | 主文先分层，再决定哪些册单独成篇 |

判断依据是**叙事独立性、发行身份、读者检索需求**。不要凭文件名或册数猜形态，也不要因为"是一套书"就把独立作品写成一篇流水账。

## 3. 2.1 字段清单

- **漫画**：原名、中文名、港台译名、类型、作者、连载杂志或平台、连载期间、原版出版信息、**读者实际使用的版本**、阅读方向、题材、连载状态、卷数或话数、英文标题、内容属性。
- **小说**：原名、中文名、港台译名、类型、作者、插画、连载平台或出版方式、出版期间、原版出版信息、**读者实际使用的版本**、题材、状态、卷数、英文标题、内容属性。

**「收藏版本」只表示本条目要逐项核对的那一版，不等于作品唯一的版本。** 不同版本的出版社、译者、日期、ISBN 和删改集中写在 2.2，**不要和原版信息混成一组**。

## 4. 2.2 至少说明四件事

1. **原版、再版、爱藏版、豪华版、合订本、译本**的先后与差异；
2. **连载中断、改刊、停刊、修订或删改**情况；
3. **改编为影视、游戏或其他载体**的时间线与接口（**只写接口，不写改编作剧情**）；
4. **本条目的 2.5 分卷表究竟以哪一版为准**。

出版社、丛书、译者、出版年、ISBN **必须逐项核对，不能从相近版本套用**。

## 5. 2.5 分卷 / 分册一览（表格 + 每卷简介）

表格上方先写一句：**本表依据哪个版本**，以及**卷名的处理方式**。固定四列：

```markdown
本表依据 <版本>；卷名：有官方卷名用官方，无则写「第N卷」。

| 卷 | 卷名 | 收藏版本出版年 | 收藏版本 ISBN |
|----|------|----------------|---------------|
| 第1卷 | <官方卷名，无则「第1卷」> | 1995 | 9789576431722 |
| 第2卷 | 第2卷 | 待核实 | 待核实 |

**分卷简介**

- **第1卷**：本卷的主线事件与收束。
- **第2卷**：本卷的主线事件与收束。
```

**表格规则**：

1. 卷号是排序锚，按实际出版顺序编号；
2. 卷名用官方副标题，**没有官方卷名时不要自拟**，直接写「第 N 卷」；
3. 出版年只填已核实的年份，否则写 `待核实`；
4. ISBN 逐卷核对，查不到写 `待核实`——**绝不估算或按邻卷推算**；
5. 行数与条目声明的卷数一致；
6. **其他版本的 ISBN 和年份放 2.2**，不重复占表。

**分卷简介规则**：每卷一条、1–3 句，**只写该卷的主线、关键转折和落点**；不提前概述后卷；不堆形容词；**不把全书梗概复制到每一卷**；事件要归到实际发生的那一卷。

## 6. 第 5 章的内容重点

**漫画**：分格与页面节奏、视线引导、跨页与无对白页的用法、黑白网点或彩色处理、背景密度、拟声词与手写字。**手法要挂到具体场景。**

- ❌ 画风精美，分镜极具张力。
- ✅ 每卷开篇用两页无对白全景交代季节与战线变化；主角决断的段落固定收成三段窄格，把犹豫压缩成节奏。

**小说**：叙事视角、时间结构、语言节奏、对白比重、意象系统、可靠或不可靠叙述、文体变化。引用原文时保持必要长度，并**注明版本和位置**，不要把评论写成作者原句。

**改编关系**：有改编时单列一节，写源作品、改编范围、删改或新增内容及其效果。**原作条目不代写改编作剧情，改编作条目也不把原作细节当成自身事实。**

## 7. 主文与分册怎么分

需要主文时：主文承担**合集定位、出版版本、分册索引、时间线和阅读顺序**；单册条目承担**自身剧情、创作特色和版本差异**。

**不必给每一册都生成完整 9 章。** 独立故事线、正传核心卷、读者高频检索的册优先单独成篇；短篇、重复性高、只作为合集组成部分的册，由主文的分册表和简介覆盖即可。这个取舍要在交付说明里写清理由。

## 8. 失败路径（On Failure）

- **体裁或形态判不出**（同名漫画 / 小说并存、看不出是不是一套）→ **先查证或确认再动笔**；判错的代价是整篇的分析方法都用错。
- **拿不到某一版的 ISBN 或出版年** → 写 `待核实`，**绝不按邻卷推算或从相近版本套用**。
- **卷名没有官方的** → 写「第 N 卷」，不自拟。
- **材料只到"能列卷名"的程度** → 2.5 表照做、分卷简介写短或注明"材料不足，未展开"；**不要**拿全书梗概充数。

## 9. 自检（每项不通过 → 回哪一步）

1. 已明确本条目覆盖一部作品还是一套合集？→ 没有：回 §2。
2. 2.1 字段独立成行，**收藏版本与原版信息没有混成一组**？→ 混了：回 §3。
3. 2.5 表格的列名、顺序、行数与声明的卷数一致，**表上方写明了依据哪一版**？→ 不符：回 §5。
4. 每个 ISBN、出版社、译者、出版年、卷名都有来源，未核实的写着 `待核实`？→ 没有：回 §5 与 `fact-check`。
5. 分卷简介没有跨卷提前剧透、也没有重复全书梗概？→ 有：回 §5。
6. 第 5 章的分镜或文体分析挂到了具体场景？→ 没有：回 §6。
7. 改编关系只留接口，没有把改编作或原作的内容当成本作事实？→ 有：回 §6。
