# 题记

**题记是点睛之笔**：挑最能代表全作气质的一处，短而准。它不是简介、不是剧情概括、不是一句话总结（总结在第 9 章）。

> **下面的例子都是示范，不是模板**：照形状抄没有意义，重点是"这处是不是点睛"。
> 文中 `sample:<文件名>` 指 `skills/atlas/references/samples/` 里的成品，**按需只读你要看的那一节**。

## 1. 先找材料，再定写法（顺序不能倒）

**写法由手上有什么材料决定。** 介质（游戏 / 动画 / 漫画 / 电影 / 小说）只影响"哪类材料更容易找到"，**不决定你必须用哪一类**——别把"某部作品碰巧有歌词"当成"这类作品该引歌词"。

材料类型，按常见程度：

1. **台词**（最常见，优先找）——角色台词、经典对白、旁白 / Narrator 的句子。
   **台词不一定是"名句"**：选那句能代表作品气质的即可，冷门但对味的比烂大街的更有辨识度。
2. **歌词**——OP / ED / 插入歌 / 印象曲。动画与游戏里常见，但不等于默认答案。
3. **诗**——角色诗、剧情诗、彩蛋诗。古装 / 武侠 / 仙侠 / 历史 / 神话题材的社群常有系统整理。
4. **原文叙述句**——原作漫画 / 小说的叙述与独白、剧本台词。
5. 同系列 / 同世界观作品的以上材料（可引，**署名必须写明是哪一部**）。

## 2. 怎么找：按材料类型分别试，别只搜一个词

- 台词：`<作品名> 名台詞` / `<作品名> 经典台词` / `<角色名> セリフ` / `<作品名> quotes` / `<作品名> 名场面`
- 歌词：`<作品名> OP 歌詞` / `<作品名> ED 歌詞` / `<歌名> 歌词`
- 诗：`<作品名> 角色诗` / `<作品名> 诗词` / `<角色名> 主题诗`
- 原文：`<作品名> 名シーン` / `<作品名> 原文 引用`

**"搜不到"是完全正常的结局，走【场景式】就是合格答案。**
**编一句"像台词"的话再回头找出处 = 硬伤。**

## 3. 三种写法

### 3.1 引用式（手上有可引原文时）

**格式契约**（一行一种语言，原文行与中文行成对；最后一行署名）：

```
:::epigraph
<原文行>
<该行的中文>
——<角色名或来源>《<作品名>》<卷 / 话 / 场景>
:::
```

> `《作品名》` 与卷 / 话 / 场景**能查到就补**；**引本作自己的内容时可省作品名**，**引同系列或别的作品时必须写清是哪一部**。

- **逐行交替**：一行原文 + 该行的中文，成对重复。**不要「原文一整段、中文一整段」**——那样读者对不上句（哪句配哪句看不出来）。
- 原文按**出处自己的断行**成行，一行只放一种语言（不与译文混排）；本来就是一句话的，就是"原文一行 + 译文一行"，不按子句硬拆。
- **原文行用作品的原始语言**（日式写日文、欧美写英文）；**不要把本地化版本当原文行**。本来就是中文的台词直接成行，不需要译文。
- 只拿到大意、原始语言一个字都没拿到 → 退回场景式。

> 想看实际排布：`sample:16bit的感动（TV动画）_WIKI.md`（歌词，日文）、`sample:上古卷轴_V_天际_WIKI.md`（台词，英文）—— 只看题记块。

### 3.2 场景式（拿不到可引原文时的默认）

从作品世界内部写 **2–6 行**：地点、天气、物件、人物正在经历的某个瞬间。自己写的，**不加署名行**。

- 每行都要有具体画面：地名、天气、物件、动作、职业细节。
- 人物的过去与使命靠意象暗示；**不复述剧情、不揭关键反转**。
- 不把话说满。

> 想看合格的场景式题记：`sample:007_初露锋芒_WIKI.md` —— 只看题记块。

### 3.3 诗句式（古装 / 武侠 / 仙侠 / 历史 / 神话题材）

这类题材**往往能检索到作品内的诗**——优先引原作的诗，而不是自己写。

- 引原作诗 → 走引用式的署名规则（注明角色与出处）。
- 自己写 → 四句、节奏整齐，**可以点到关键舞台与事件**（「仙灵岛上结仙缘，比武招亲动少年」这一档——这类题材的经典题记本身就这么写）；但**不写结局、不揭关键反转**，收在余韵；**不堆「江湖」「宿命」「山河」这类空词**；自创诗不加署名行。
- **三式的剧情尺度不一样**：**引用式**（照引原文）与**场景式**（自写画面）**不点剧情**；**只有诗句式**允许点舞台与事件。
- 现代、写实题材不要硬写诗。

## 4. 署名行（**要写**）

- 作品内的台词 / 旁白 / 歌词 / 诗 → 写**角色名或来源**；能查到就补作品、卷 / 话 / 场景。
- 外部引文（与该作气质呼应的名人句、扉页题词）→ 写原作者或出处。
- **引本作自己的内容**：作品名可省（文章本身就是这一部）；**引同系列 / 别的作品**：必须写清是哪一部。
- 只标出处，**不夹带评价**；单独成行，以 `——` 开头。
- **能查到是谁说的就必须补**（引用式尤其别省）——台词通常出自某个有名字的角色，去把那个名字查出来。
- **当那句"名台词"其实是借角色之口引用的外来名句**（莎剧、古诗、经句、名言）→ **不要把它署给角色**：改用本作原创的一处；要保留它，就按**外部引文**署名原作者，并注明是引用。
- 场景式与自创诗句**不加**署名行。

## 5. 剩下的名句不要丢

检索往往会搜到一批名句 / 名场面，**题记只挑一处点睛**，其余写进骨架里的 `## 名台词与名场面`（见 `wiki-skeleton`），每条标出处。

## 6. 禁区（出现即整段不合格）

- **主语是作品**：「这款游戏」「这部剧」「本作」。
- **谈发行层的事**：销量、市场、制作流程、行业地位、改编取舍。
- **拿别的作品作比较**。判别法：指**作品结构或发行层**的指称出局（第 X 部、初代、前作、第一季、续作）；指**世界内时间**的指称允许（多年之后、战争结束后的那个冬天、又一次）。
- **换成任何一部同类作品也完全成立的空句**。

## 7. 核实强度（引用式的门槛）

引用式的唯一前提是**能指到出处**：哪部作品、谁的台词或旁白、哪一段。

- **先有原文再写题记**；不要凭印象写一句再回头找出处。
- 同一句的不同译文、不同语种、不同表记或断句**算同一句**，取通行写法即可，不因措辞差异弃用。
- 只有当比对的两句**意思不同**时，才算没核实到 → 退回场景式。
- 题记是引文：**不走**正文那种"逐字核对到第几集 / 第几卷"的强度（那属于 `fact-check`）。

## 8. 自检（每项不通过 → 回哪一步）

1. 这一处是不是**点睛**——换一部同类作品还成立吗？→ 成立就是空句：回 §3 重写。
2. 有没有把"某部作品的碰巧情况"当成规则？（介质 ≠ 材料类型；台词优先）→ 有：回 §1 重找材料。
3. 署名齐不齐？（能查到是谁说的、出自哪里；引别作写清是哪一部）→ 不齐：回 §4。
4. 原文行是不是作品原始语言？→ 不是：回 §3.1。
5. 有没有把简介 / 概括 / 总结混进题记？→ 有：删掉（那是第 1 章与第 9 章）。（诗句式**可以点到关键舞台与事件**，但那是「点」，不是把剧情线概括一遍。）
6. 长度克制吗？（通常 2–6 行）→ 太长：回 §1 重挑。
7. 检索到的其余名句，有去处吗？→ 没有：回 §5。
8. 原文行与中文行**逐行成对**吗？（不是"原文一段、中文一段"）→ 不是：回 §3.1。
