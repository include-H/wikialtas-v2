# 同一段故事被多部作品讲过

## 0. 什么时候适用

**唯一的判据是"讲的是不是同一段故事"。**

- 系统预取的**关系**里有边标明它与某条是"同一段故事"（改编 / 另一结局 / 后传接着讲），或**同级单作**里存在讲同一段的条目；
- 用户问的是跨作品问题（某角色的结局、某个设定是什么）。

**只是"同一系列"不算**：续作 / 续集讲的是**新故事**——那属于 `series-main`（层级与索引）与 `wiki-skeleton`（本作边界的处理）。

## 1. 先划本作的边界

**先确定这部作品讲到哪里为止。本作没讲到的，不要拿别的作品的结局替它收尾。**

## 2. 两边都写，并指明出处

同一段剧情另有作品讲过时：

- 写法：`本作结局中 X 牺牲；《另一部》中 X 复归`——**两个叙述都写出来，并标明各自出自哪一部**。
- **不是"谁对谁错"**：两边说法不同，通常不是谁错，而是**两个不同的叙述**。判断依据是**作品自身**，不是"哪个更全"。

### 2.1 同源改编不是"两个叙述"

**同源改编**（小说化 / 漫画化 / 重制 / 同一段故事的另一载体）**不要按 §2 写成两套并列**——它们讲的是同一段故事，没有"两边说法不同"可并列。

做法：

- 剧情按**本载体**叙述（有来源）；
- 只把**源载体的制作层事实**剔出去（配音 / 票房 / 影像与美术 / 宣发设定），别把那些当成本载体的事实；
- 在 2.2 与相关章节**标明源作品与改编关系**；
- 谁先出版、出版社怎么称呼（比如把小说叫"原作小説"）**不影响方向**——方向按契约填（改编作 → 原作）。

## 3. 跨作品问答必须连带

回答跨作品问题（某角色的结局、某个设定）时，**必须连带讲同一段故事的其他作品**并说明差异。只按当前条目口径回答，等于**把另一半事实藏起来**。
（库里同一段故事往往落在多个节点上，所以这条是常态，不是例外。）

## 4. 用系统预取的两行信息

- **同级单作**：名字（旁边有哪些兄弟条目）。
- **关系**：边（谁改编自谁、谁是谁的后传 / 另一结局）。

**关系那行说了它们是同一件事时，就得去读那一条**（用 `read_work`）——别只读当前条目就下结论。

## 5. 失败路径（On Failure）

- **关系不明 / 没读到对应条目** → 只写本作口径，并**明确标注**「同一段故事另有作品讲述，本条目未展开」；**不要**凭印象补另一部的结局。
- **只找到一方来源** → 写出能核实的那一方，另一方按 `fact-check` 的缺口处理（`待核实`）。
- **两边的权威程度差很多**（官方设定 vs 粉丝整理）→ 按来源分层处理，并在行文里体现置信差异。

## 6. 自检（每项不通过 → 回哪一步）

1. 本作讲到哪、另一部讲到哪，分清了？→ 没有：回 §1。
2. 讲同一段的其他作品，两边都出现、都标了出处？→ 漏了：回 §2。
3. 有没有拿另一部的结局替本作收尾？→ 有：删掉，回 §1。
4. 预取的关系边里说"同一件事"的，去读了没？→ 没读：回 §4。
5. 回答跨作品问题时，差异说明写了吗？→ 没写：回 §3。
