# 文风

**目标：每句话都落在一个具体对象上。** 读起来像"认真整理过"，而不是"看起来挺像文章"。

> 下面的对照是示范，不是模板。

## 1. 六条

1. **第三人称陈述**。不写「你会看到」「我们不难发现」。
2. **每段至少落在一个具体对象上**：人名、地名、日期、机制、镜头、出版信息或来源。
3. **少用连续论证套句**：「不是……而是……」「换句话说」「也正因为如此」——**章节标题里禁用**。
4. **同一个事实只在最合适的一章完整出现一次**；别的章最多一句指向。
5. **长度服从信息量**。写不动就说明缺什么材料，**不要用同义句扩写**。
6. **事实、推断、评价分开**：事实带来源；推断写明是推断；评价放在有证据的段落。

## 2. 改前 → 改后（示范）

| ❌ | ✅ |
|---|---|
| 这款神作的战斗系统简直是封神级别的天花板 | 战斗把格挡、弹反和体力条绑在同一套节奏上，逼玩家在攻防之间反复取舍 |
| 你会发现导演其实想说的是权力的代价 | 导演在三场审讯戏里重复同一机位，把权力关系压成固定构图 |
| 表面上是一部冒险片，真正讲的却是成长 | 冒险线推进的同时，主角三次拒绝求援，最后一次才开口 |
| 本片获得众多奖项与好评 | 本片获第 84 届奥斯卡最佳影片提名；Metacritic 均分 84（32 家媒体，检索于 2026-09） |
| 剧情最后真相大白，结局令人回味 | 结局揭穿委托人本人就是纵火者，主角销毁证据并辞去职务 |
| 画风精美，音乐震撼 | 每卷开篇用两页无对白全景交代季节变化；同一段主题旋律出现在三次死亡场景 |
| 系统丰富，玩法多样，可玩性极高 | 主线之外有四条公会线，各有独立任务链和结局，可在同一周目并行推进 |

**判别法**：这句话**换成任何一部同类作品是否也完全成立**？成立 → 它是空话，删掉或改成具体的那一处。

## 3. 事实、推断、评价怎么分

- **事实**：带来源（见 `fact-check`）。例：`本片获第 84 届奥斯卡最佳影片提名`。
- **推断**：写明是推断，且给出观察依据。例：`三场审讯戏使用同一机位，可视作导演对权力关系的固定化处理`——不写成"导演想说的是"。
- **评价**：放在有证据的段落里，点具体问题，不写私人好恶。

## 4. 失败路径（On Failure）

- **信息不足、写不动** → 说明缺什么材料（交回去补），**不要**用同义句、排比句、升华句填充。
- **用户说"读起来像 AI 写的"** → **不要整篇重写**：逐段定位属于哪一类（空泛赞美 / 论证套句 / 无依据评价 / 第二人称），按 §1 逐条改，只动这些句子。
- **润色时发现事实问题** → 交给 `fact-check` 处理（`待核实` / 删行），**不要**用模糊措辞把事实问题盖过去。
- **改完反而更长了** → 回头看是不是灌了水：长度服从信息量。

## 5. 自检（每项不通过 → 回哪一步）

1. 还有第二人称（「你会看到」）吗？→ 有：回 §1.1。
2. 每个段落都落在具体对象上了吗？→ 有空段：回 §1.2。
3. 还有空泛赞美 / 无依据的评价吗？→ 有：按 §2 改成具体事实。
4. 章节标题里有论证套句吗？→ 有：回 §1.3。
5. 同一个事实在多章重复展开了吗？→ 是：回 §1.4。
6. 有为了凑长度写的同义句吗？→ 有：回 §1.5。
7. 推断被写成了事实、评价没有证据支撑？→ 有：回 §3。
