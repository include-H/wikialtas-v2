## 用法（模型）

- `sample:<文件名>` 指这里的成品：**只写文件名**——加载器在 `skills/samples/**` 里**按文件名递归找**，所以分组不影响引用。
- **只读你要看的那一节**（例：写题记只读题记块），**不要整篇照抄**——照形状抄没有意义。
- 它们**不是**你手头的目标作品：里面的作品名、年份、人物都无关，**别把内容带进正文**。

## 用法（维护者）

- **回归**：改技能 / 提示词后，用这些目标各重跑一次生成，逐篇比对信息密度、证据落点、章节职责、语气有没有回退。
- **对齐**：每条技能规则都要能在这些篇里找到体现；找不到体现的规则 = 补丁，删掉或降级。
- **不许改**：发现某处不达标 → **先讨论**（记进 `docs/skills.md` 的待定），不要私自"修正"。
- **已知薄弱处**（回归时的重点）：电影 / 电视剧的第 5 章影像分析（拿不到一手摄影/剪辑材料）、漫画的第 5 章分镜分析（拿不到原作页面）、小说与网文的第 5 章文体分析（拿不到正文）、多数篇的第 8 章（可引原文少）。
